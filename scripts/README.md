The `scripts` folder contains the packages for different science use-cases, where each package
only contains Python scripts (e.g. `.py` files) illustrating how to perform a specific task.

For Jupyter Notebook examples illustrating the same use-cases, see the `notebooks` folder.

Refer to the `autogalaxy_workspace/README.md` file or the readthedocs documentation for a description of which folder
you should go into next if you are unsure.

# Folders

- `guides`: Step-by-step guides illustrating many important things, including the core API, analysing modeling results and much more.
- `imaging`: Examples for galaxies observed with CCD imaging (e.g. Hubble, Euclid).
- `interferometer`: Examples for galaxies observed with an interferometer (e.g. ALMA, JVLA).
- `ellipse`: Examples for perform ellipse isophote fitting on galaxy images.
- `multi_dataset`: Examples for multiple datasets simultaneously (E.g. multi-wavelength imaging, imaging and interferometry).
- `multi_galaxy`: Examples for modeling 2+ blended galaxies simultaneously, each with its own free light model.
- `cluster`: Examples for modeling a cluster field's light — a BCG plus a catalogue-driven member population.

The **HowToGalaxy** lecture series, which teaches inexperienced scientists what galaxy fitting is and how to use
**PyAutoGalaxy**, now lives in its own repository: <https://github.com/PyAutoLabs/HowToGalaxy>
